YouTube PWA

Deploy this entire folder to Netlify (or another HTTPS host).
Do not deploy only index.html.

After deployment:
1. Open the HTTPS site in Chrome on Android.
2. Install it from Chrome's menu.
3. If an older version is already installed, uninstall it first and reinstall
   so Chrome picks up the new manifest/service worker.

The uploaded YouTube SVG is used as the master icon asset.
192x192 and 512x512 PNG versions are supplied for Android PWA manifest
compatibility.
